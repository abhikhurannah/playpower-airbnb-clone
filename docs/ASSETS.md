# Asset provenance

The user's supplied `stay-finder-56-main.zip` provides the original four listing illustrations, starter components, dependencies and baseline UI. Those assets and files are retained.

The Candolim property photos, host/reviewer avatars, Cereal font, laurel graphics and discount icon were downloaded from assets observed in the rendered assignment reference: https://airbnb-clone-umber-two.vercel.app/ . The user explicitly authorized reuse of downloaded images and icons.

`src/data/photos.json` records the 43 local photo paths in their observed order. `asset-manifest.json` records local reference assets and their origin URLs. These remain third-party assets reused for this assessment; no ownership or general redistribution license is asserted. Existing Lucide icons and Radix/Shadcn components remain under their respective licenses.

The reference application's JavaScript, HTML application source and stylesheets were not copied. New behavior and layout code were authored on top of the user-supplied starter source. The production architecture image is an original diagram generated by `scripts/architecture.py`.
